# Projeto de Software C++

Este é um projeto desenvolvido para a disciplina de Engenharia de Software, demonstrando o uso de GitFlow, TDD e boas práticas de estruturação de projetos em C++.

## Estrutura do Diretório

* `/src`: Código fonte da aplicação.
* `/include`: Arquivos de cabeçalho.
* `/bin`: Executáveis e binários gerados na compilação.
* `/test`: Código fonte relacionado aos testes automatizados.
* `/doc`: Documentação do projeto.

## Compilação

Na raiz do projeto, utilize o comando `make` para compilar a aplicação principal.
Para compilar os testes, utilize o comando `make test`.

## Funcionalidades

1. **Maiúsculas**: Converte uma string para maiúsculas.
2. **Fibonacci**: Calcula o N-ésimo termo da sequência de Fibonacci.
3. **Run-Length Encoding**: Algoritmo de compressão de dados.
